# Portfolio

Personal portfolio site built with [Jekyll](https://jekyllrb.com/) and hosted on GitHub Pages.

**Live site:** https://mlp-20.github.io

## Structure

```
_config.yml        Site settings: name, description, social links, nav, theme
_layouts/          default.html (sidebar + nav) and post.html (blog posts)
_posts/            Blog posts, named YYYY-MM-DD-title.md
assets/            css/custom.css, js/, img/ (profile.jpg, screenshots), cv.pdf
index.md           Home: intro, featured projects, experience, contact
projects.md        All projects
blog.md            Post list (auto-generated from _posts/)
books.md           Reading list
about.md           Bio, skills, experience
contact.md         Contact links
robots.txt, sitemap.xml, llms.txt   SEO / crawler files (generated by Liquid)
```

## Run locally

Requires Ruby 3.x and Bundler.

```bash
bundle install
bundle exec jekyll serve
```

Then open http://localhost:4000.

## Deploy

1. Create a public GitHub repo named exactly `mlp-20.github.io`.
2. Push this folder to it.
3. In **Settings → Pages**, set the source to "Deploy from a branch" → `main` / `(root)`.

## Theme

Built with the [Minimal](https://github.com/pages-themes/minimal) theme for GitHub Pages.
